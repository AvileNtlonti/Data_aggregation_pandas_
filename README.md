# Data_aggregation_pandas_
Pandas project focused on retail sales data aggregation, grouping, and exploratory analysis. Practiced `groupby()`, `agg()`, summary statistics, frequency analysis, and sorting.
### Retail Sales Data Aggregation with Pandas

This project focuses on practicing **data aggregation and grouping using Python and Pandas** with a retail sales dataset. I worked with summary statistics such as `sum()`, `mean()`, `median()`, `max()`, and `nunique()`, as well as grouping data using `groupby()` and `agg()`.



### Skills Practiced

* Python
* Pandas
* Data Aggregation
* `groupby()`
* `agg()`
* `sum()`, `mean()`, `median()`, `max()`, `nunique()`
* Grouping by multiple columns
* Exploratory Data Analysis (EDA)
